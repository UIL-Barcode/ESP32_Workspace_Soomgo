> 작성 방법: 아래 표/항목의 `-` 를 채우거나 지우면서 채팅으로 불러주시면 제가 이 파일에 반영합니다.
> 다 채워지면 이 문서를 기준으로 위젯별 구현 작업을 `docs/DEVELOPMENT.md`에 M번호로 쪼갭니다.

## 1. 사용 시나리오

- **누가 보나요?** 본인 1인 / 여러 명 → `-본인 1인`
- **어디서 접속하나요?** 봇이 도는 PC에서 로컬로만 / 다른 PC·폰에서 원격으로도 → `-`
- **언제 보나요?** 상시 모니터링(켜두고 흘끗 봄) / 필요할 때만 켜서 확인 → `-`
- **접속 시 인증이 필요한가요?** (원격이면 특히 중요 — 지금 대시보드엔 인증이 전혀 없음) → `-`

## 3. 특히 구체화가 필요한 두 항목

**"예측가"**
- 이게 정확히 뭔가요? (a) 알고리즘 신호(`run_live`)를 그대로 보여주는 것 (b) 별도 예측 모델(회귀/ML)을 새로 만드는 것 (c) 단순히 최근 캔들 추세선 → `-`
- (b)라면 이건 대시보드 문제가 아니라 `algorithm/` 쪽에 새 기능이 먼저 필요합니다 — 범위가 커집니다.

**"관심종목"**
- 지금 코드엔 관심종목(watchlist) 개념 자체가 없습니다 (종목 마스터 캐시만 있음).
- 어떻게 관리하나요? (a) 디스코드 명령으로 추가/삭제 (`!관심 추가 005930` 같은 것 신규 필요) (b) 대시보드 화면에서 직접 추가/삭제 (c) JSON 파일 직접 편집 → `-`

## 4. 커스터마이징(편집 가능) 범위

- 위젯 표시/숨김 On-Off → 필요 여부: `-`
- 위젯 위치 이동(드래그) → 필요 여부: `-`
- 위젯 크기 조절 → 필요 여부: `-`
- 위젯 내부 파라미터 변경 (예: "관심종목 현재가" 위젯에 어떤 종목을 넣을지) → 필요 여부: `-`
- 레이아웃 저장 위치: 브라우저에만(새로고침하면 유지, 다른 기기에선 초기화) / 파일로 영구 저장(모든 기기에서 동일) → `-`

## 5. 비기능 요구사항

- 동시 접속(같은 대시보드를 여러 창/기기에서 동시에 볼 일이 있나요?) → `-`
- 반응 속도 기대치(몇 초 이내 갱신이면 충분한가요?) → `-`
- 그 외 제약이나 하고 싶은 말 → `-`
