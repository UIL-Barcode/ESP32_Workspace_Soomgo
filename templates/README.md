# 📂 Templates Directory

이 폴더는 새로운 프로젝트를 시작할 때 기준이 되는 **표준 프로젝트 뼈대(Boilerplate)**를 보관하는 곳입니다. 

매번 개발 환경을 새롭게 설정할 필요 없이, 아래의 순서에 따라 본 폴더의 프로젝트를 복사하여 사용하시기 바랍니다.

---

## 🚀 프로젝트 시작 가이드 (복사하여 사용하기)

새로운 실습이나 기능을 구현할 때는 반드시 다음 절차를 따라주세요.

### 1. 폴더 복사 및 이름 변경
* `default_project` 폴더를 통째로 복사(`Ctrl + C`)합니다.
* `projects/` 폴더 아래에 붙여넣기(`Ctrl + V`) 합니다.
* 폴더 이름을 프로젝트 목적에 맞게 변경합니다. (예: `projects/01_led_control`)

### 2. VS Code에서 폴더 열기
* VS Code 실행 후 **[File] - [Open Folder]**를 선택합니다.
* 방금 생성한 프로젝트 폴더(`projects/01_led_control`)를 단독으로 엽니다.

### 3. VS Code 환경 설정 동기화 (필수 ⭐)
복사한 프로젝트는 이전 작업 환경의 경로 정보를 가지고 있지 않습니다. 아래 명령어를 통해 현재 PC 환경에 맞게 초기화해야 합니다.
1. `Ctrl + Shift + P` 를 눌러 명령 팔레트를 엽니다.
2. **`ESP-IDF: Add vscode configuration folder`**를 검색하여 실행합니다.
3. 자동으로 `.vscode` 폴더가 생성되며, 현재 PC의 SDK 경로가 설정됩니다.

### 4. 빌드 및 테스트
* 하단 상태 표시줄의 **[Build] (⚡ 아이콘)** 버튼을 눌러 컴파일을 진행합니다.
* 첫 빌드 시에는 SDK 환경을 분석하므로 약간의 시간이 소요될 수 있습니다.

---

## 🏗️ 템플릿 구조 안내
* **`main/`**: 실제 어플리케이션 코드를 작성하는 공간입니다.
* **`CMakeLists.txt`**: 상위 폴더의 `driverlib`을 자동으로 참조하도록 설계되어 있어, 별도의 설정 없이 공통 드라이버를 즉시 호출할 수 있습니다.

---

## 💡 주의사항
* 본 `templates` 폴더 내의 원본 파일은 직접 수정하지 마십시오. 
* 수정이 필요한 공통 설정은 멘토와 상의 후 반영하시기 바랍니다.
